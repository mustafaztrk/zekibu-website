# Zekibu Web Sitesi

Zekibu Matematik mobil uygulamasının resmi web sitesi.

## Sayfalar

- `index.html` — Landing page
- `privacy.html` — Gizlilik Politikası (TR + EN)
- `support.html` — Destek ve sıkça sorulan sorular

## Yayın

GitHub Pages üzerinden yayınlanır. `main` branch'in kökü site olarak servis edilir.

URL: `https://<github-kullaniciadi>.github.io/zekibu-website/`

İleride özel domain bağlanabilir (`zekibu.com`).

## Geliştirme

Statik HTML/CSS, build adımı yok. Dosyaları açıp tarayıcıda görüntüleyebilirsin:

```bash
open index.html
```

Veya küçük bir lokal sunucu:

```bash
python3 -m http.server 8000
```
